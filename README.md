# ☀ Utility-Scale PV Economic Analysis

## Photovoltaic System Simulation, Energy Yield & Economic Assessment

---

# 📌 Project Overview

This project focuses on the technical and economic evaluation of a utility-scale photovoltaic (PV) system.

The work includes:
- photovoltaic energy yield simulation
- self-consumption analysis
- grid interaction evaluation
- sustainability assessment
- economic feasibility analysis

The project was developed as part of my International Energy Engineering studies at OTH Amberg-Weiden, Germany.

---

# 🎯 Objectives

✔ Evaluate utility-scale PV system performance  
✔ Analyze annual energy production  
✔ Assess economic feasibility and profitability  
✔ Investigate self-consumption optimization  
✔ Estimate CO₂ emission reduction potential  
✔ Support sustainable energy transition strategies
